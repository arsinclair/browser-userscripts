# Browser Userscripts

A curated collection of user scripts and user styles for various websites, focused on small quality-of-life tweaks and visual polish. This repo is intended to grow over time as new sites are added and existing tweaks are expanded.

## Bandcamp

- Bandcamp Restyler — Adds polished borders, labels, and typography to Bandcamp purchase, album, credits, and bio sections. https://github.com/arsinclair/browser-userscripts/raw/master/user-styles/bandcamp-restyler.user.css
- Bandcamp Restyler Color Sync — Syncs Bandcamp Restyler’s colors with each page’s custom text and background colors. https://github.com/arsinclair/browser-userscripts/raw/dist/bandcamp-restyler-color-sync.user.js
- Bandcamp Bio Untruncate — Shows full Bandcamp artist bios by removing truncation and More/Less controls. https://github.com/arsinclair/browser-userscripts/raw/dist/bandcamp-bio-untruncate.user.js
- Bandcamp Redeem Yes Button Clicker — Automatically confirms Bandcamp redemption prompts by clicking “Yes”. https://github.com/arsinclair/browser-userscripts/raw/dist/bandcamp-redeem-yes-button-clicker.user.js

## getmusic.fm

- getmusic.fm Auto-redeemer — Opens redemption links directly in Bandcamp and bypasses voucher redirects. https://github.com/arsinclair/browser-userscripts/raw/dist/getmusic-redeem-button-transformer.user.js
